# Security

Security fixes target the latest stable release. Update the server and clients
before reporting an issue that may already be fixed. Preview builds are for
testing and may contain unfinished changes.

Report a suspected vulnerability through
[GitHub's private vulnerability reporting](https://github.com/vitofico/spunto/security/advisories/new).
Include the affected version, installation type, steps to reproduce and the
likely impact. Use synthetic notes and redact tokens, passwords, provider keys,
backups and personal information. Please do not disclose an unpatched
vulnerability or sensitive data in a public issue.

Run internet-facing servers behind HTTPS, keep the database and backups private,
and grant device, agent and collaboration permissions carefully. Only install
plugins you trust. The [operations guide](docs/operations.md) covers deployment,
backup and recovery; the [privacy policy](PRIVACY.md) describes data boundaries.
