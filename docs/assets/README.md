# README screenshots

The `web-*.png` images were captured from the running Spunto web client on
2026-10-28, at source revision `f6992b7`, with a disposable local SQLite server.
They are unaltered browser captures at a 1440 × 1060 viewport; Appearance uses
a full-page capture. They contain only original fictional Darth Vader notes.
No production account or library was used.

The notes were created through the capture editor. The capture workflow checked
that all five notes survived reload, toggled a checklist item, edited and saved
the Death Star note, reopened it, searched `#imperial` to find its two matching
notes, and expanded revision history. It then changed all five built-in palettes
through Appearance, selected light/dark modes, and selected both Plain and Artwork
backgrounds. The final browser run reported no page errors. Every selected image
was visually inspected before inclusion.
