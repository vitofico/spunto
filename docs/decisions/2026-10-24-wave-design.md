# Themed wave visual refresh

The approved unlock concept uses open, fine-line waves and a text action instead
of a fingerprint symbol. Carry this visual language through the app header,
sign-in and onboarding branding, and appearance previews. Keep decoration out of
note prose and editing fields.

The wordmark is always `spunto.`. Its period uses the active theme's accent,
including custom packs, custom accents and wallpaper colours. The wave uses the
same resolved accent. Elettrica's indigo and violet are one palette, not fixed
brand colours: Carta, Ardesia, Salvia and Corallo remain available in both modes.

Use consistent rounded controls, quiet borders, text-first note entries and
comfortable spacing. Keep the existing navigation, inline capture, reading
preferences, device overrides and theme-pack validation. The note editor's Done
action belongs in the app bar; embedded editors retain an in-place action.

Authentication remains system-owned, with automatic biometric unlock, phone
credential fallback and Back exiting a locked activity. Secure windows and the
hidden retained draft tree are unchanged. The wave is static decoration with no
accessibility actions or network-loaded assets.
