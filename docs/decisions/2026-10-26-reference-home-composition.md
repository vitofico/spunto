# Spunto home follows the approved close-up

The owner's close-up approves a new home composition. It supersedes the visual
entry-time and passage-only presentation in historical design documents 03 and
05. Those documents remain unchanged.

The home uses a large serif wordmark with search and settings in the same row,
a separate All notes picker, a compact capture field with an always visible
Save action, accent day labels and a shared rounded paper pane. Entry titles
and previews have their own compact type scale; full-note reading preferences
remain independent. Timestamps remain in accessibility descriptions and the
note's details. Filters and optional Ask stay in a quiet home options menu.

Capture tools expand when the field is focused. Long native captures retain the
docked Save action; dictation, attachments and task insertion keep their existing
flows. Preview task glyphs are circular, while their entire semantic row remains
tappable. Label pills use actual parsed labels and still open their filters.
Title/body separation never rewrites source and preserves source-line offsets
for checklist edits; single-line notes keep their whole text in the title. Only
actual parsed label occurrences move from trailing lines into pills; numeric
references and code stay visible. Compact prose uses two readable lines with
an ellipsis, while task previews retain the existing expandable fold. The archive
backing is visible only during a swipe and follows the shared pane bounds. The
notes picker reserves the More action at narrow widths and large text sizes.

Plain and Artwork remain separate from colour themes. Continuous contours sit
behind the home chrome and around the rounded opaque note pane, instead of
being interrupted by full-width timestamp and day-header surfaces.
