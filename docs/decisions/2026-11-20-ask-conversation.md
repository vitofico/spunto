# Ask conversation and note evidence

The owner approved a dedicated temporary chat for recall, brainstorming, and discussion. The speech bubble in All notes remains its direct entry. The view keeps the input visible and reveals citations and evidence passages on demand. On web, a cited note opens in a separate tab so the chat stays open. On Android, the source reader opens over the chat and closes back to the same reply.

Ask follows the latest user's language and depth of the question. It searches fresh notes on each turn. Personal recall needs evidence. When a request is for discussion, Ask can respond with general reasoning or ideas even when there are no matches. It must distinguish suggestions from information documented in notes. **Only from notes** restricts a turn to grounded replies. Valid answers can be explicitly saved, including general replies. Insufficient recall offers no Save. Existing review and confirmation rules govern proposed note writes.

Modern clients opt in when Ask 1.2 or later advertises conversation support. They allocate with a boolean conversational option, and send the optional notes-only flag on individual turns. Messages allow up to 2,000 characters and answers up to 4,000. Retrieval still uses a bounded 500-character query and at most eight sources. Older clients and servers retain the prior grounded-only contract and 500-character questions. No schema migration or new plugin permission is required.

A conversation opened from a collection is bound to that collection and its source snapshot. Only currently eligible linked notes are considered for inference. Private, archived, machine-written, externally sourced and inaccessible collection notes are excluded. The collection brief itself is excluded. Ask checks current collection eligibility before and after inference and before Save. Collection chat does not offer unrelated note-write proposals. The existing owner-only command policy, model routing and credential-bound temporary turns still apply.

The gateway fences model evidence as data, validates returned note IDs against the actual transmitted sources, and returns a bounded passage chosen from that evidence. The structured response distinguishes grounded answers, discussion, and insufficient evidence. Discussion carries no citations. A reply is retained only in the active temporary conversation unless the owner saves it. Previously authorized provider requests cannot be retracted while in progress.
