# Full-width notes on wide web screens

The owner asked to use the whole width of a wide screen for the notes list.
This revises the "no density setting" choice in historical design document 03
§13.2 for the web home only. Documents 01 to 05 remain unchanged.

The home header gains one **Full width** toggle, grouped with search, Ask and
settings at the right, shown only from 1024 px wide, where the rail is visible.
When it is on, the home column (header, capture field and notes) widens to the
page. Notes stay one per row, in the same raised paper, type, labels and
previews, so every colour theme, installed pack, light/dark mode and background
style applies unchanged.

A first version laid the notes out as a grid of tiles; the owner rejected it,
because the request was for full-width notes, not more notes per row.

The column stays the default. The choice is stored locally per device, like the
background style, and is not sent to the server. Below 1024 px the toggle is
hidden and the column is always used, so phones are unaffected. Label, archive,
trash and plugin views, the note reader and Android keep the column.
