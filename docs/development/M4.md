# M4: AI gateway and first AI plugins

M4 development remains local under the owner's authorization to use subagents. No commits, pushes, pull requests, releases or deployments were made. Approved documents 01–05 and the owner's existing edits are preserved. Blinko and retrieval checks use synthetic fixtures only.

## Implemented

- Environment-only profiles with independent chat, embeddings, transcription and vision bindings, explicit per-plugin routing, safe destination disclosure and owner-only fixed-content health checks.
- OpenAI-compatible REST and the native Anthropic Messages SDK, closed strict output models, bounded semantic validation and one corrective retry. Native SDK redirects are disabled so provider credentials and note content stay with the configured endpoint. Provider quirks persist by endpoint/model; provider keys, prompts and response bodies stay out of logs and public metadata.
- Generation-bound plugin AI and vector facades. Authoritative note checks refuse private, machine and trashed content, enforce external-note scope, fence note data, and reject borrowed note text pasted into a raw prompt or query.
- SQLite-vec 0.1.9 in the same database, paragraph chunks, model/dimension/prefix fingerprints, per-route coherent indexes, transactional privacy/purge cleanup and backfill before atomic model activation. Queries and writes pin their model key across concurrent model changes, while each caller retains its own profile credentials and limits. Core leases and provider requests batch at most 32 notes/texts; every vector is validated before writing any chunk in the lease.
- Profile priority, rate/concurrency limits and fair shares. Provider outages preserve queued job attempts. Privacy and eligibility changes during queued indexing or label hooks recheck notes without spending retry budgets or disabling the plugin; dismissal hooks skip notes that became private, machine-written or unavailable. Validation failures fail closed.
- Label suggestions with scoped vocabulary, dismissed-label memory and opt-in automatic acceptance of existing labels; semantic search with core filters and reciprocal rank fusion; Related panels and its read-only MCP tool; grounded Ask with citations and an explicit idempotent save as a machine-created note. Unsaved answers remain in bounded expiring memory.
- AI settings, profile checks, index progress and recovery, per-plugin routing, keyword-first hybrid search, typed hit markers, live panels and command forms/save actions in the web app.
- Schema 4 migration, vector-aware snapshot/restore validation and `spunto ai reindex [--drop]` with the server stopped.

Fresh installs keep the four AI switches on and Waiting when a required capability is unbound; they expose no contributions then. New plugins on an upgrade start off. Saved owner switches and environment pins win. The four M2 plugins still default off. An unconfigured instance queues no AI jobs and makes no provider calls.
